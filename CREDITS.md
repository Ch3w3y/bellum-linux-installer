# Credits and project lineage

[Joheb Rahman (joepaji)](https://github.com/joepaji) created the
[original Bellum Linux Installer](https://github.com/joepaji/bellum-linux-installer).
This repository is a successor maintained independently by Ch3w3y and other
contributors. Its history retains Joheb’s foundational commits and authorship.

The fork incorporated the original project's v2.1.0 commit into its Git
ancestry while retaining this successor’s independently hardened installer
tree. The upstream commit bundles an EAC runtime and changes launch and
install behavior that require separate security and compatibility review;
recording ancestry does not claim those changes are shipped here. Future
upstream changes should be reviewed and credited before selective adoption.

This is a community project, not official support from Astarte Industries.
